JOGO DE PLATAFORMA EM PYTHON: Ataque da Natureza

História e Jogabilidade:
1. O personagem precisa pegar um cristal no topo do mapa para vencer.
2. O jogador deve evitar os inimigos, eles são letais!
3. Os controles são as setas do teclado ou A e D para se mover e a barra de espaço para pular!

Como Rodar:
1. Instale as bibliotecas usadas no projeto:
1.1. Abra o terminal e cole o comando: ```pip install pgzero```
2. Para rodar o jogo, execute game.py

Aproveite!



###### ENGLISH VERSION ######

PYTHON PLATFORM GAME: Nature's Attack

Story and Gameplay:
1. The character needs to collect a crystal at the top of the map to win.
2. The player must avoid the enemies; they are lethal!
3. The controls are the arrow keys or A and D to move, and the spacebar to jump!

How to run:
1. Install the libraries used in the project:
1.1. Open the terminal and paste the command: ```pip install pgzero```
2. To run the game, execute game.py
